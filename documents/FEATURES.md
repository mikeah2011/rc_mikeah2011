# 主要功能与开发摘要

项目定位是**内部 HTTP 通知服务**，不是多渠道消息平台。完整功能和代码定位统一维护在 [功能说明](FEATURE_OVERVIEW.md)，避免不同文档重复描述而不一致。

本轮聚焦接收、持久化、Outbox 发布、HTTP 有限重试、最终失败与人工重投闭环。默认 database queue，Redis/Horizon 不是运行前提；邮件、短信及多目标广播暂不实施。

设计边界、可靠性语义和技术取舍见 [SA/SD](SA_SD.md)，分批安排和后续工作见 [实施计划](PLAN.md)。

开发规则：一个批次围绕一个目标，包含必要实现、回归用例和相关文档；不把规划、占位文件或仅在本地验证的能力称作生产就绪。
